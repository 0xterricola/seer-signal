# Seer / Signal — review walkthrough

Created for @0xterricola. All examples and transactions are simulated.

1. **Homepage:** switch the application lenses in the hero. Each previews the kind of question its application answers.
2. **Explorer:** inspect a market and expand its resolution context. Filter by market type to see how units and simulations adapt.
3. **Deep:** load sample agent forecasts. The disagreement map reveals differences; filter gaps of at least five points and review the batch, ordered by disagreement with liquidity alongside. Edit a score and navigate away and back to see draft persistence.
4. **Futarchy:** switch proposals and compare pass/fail forecasts on the same success measure. The DAO retains the decision.
5. **Opportunity:** inspect the distinct submission briefs and shortlist candidates. Review the rubric before simulating a selection forecast.
6. **Risk Pricing:** select two or three protocols and compare their annualized estimates, definitions, liquidity, and activity.

Try the light theme and a narrow window. Design notes explain the Electric Foundation adaptations.

## Repository and deployment

Suggested repository: `seer-signal`. Place the contents of this package at its root. Publish the `site/` directory using a static host; no build step is required. The source repository and preview image do not replace the six public demo links required by the bounty. README.md contains the route checklist.
